# 📄 DocuChat — AI-Powered Document Q&A

A Retrieval-Augmented Generation (RAG) system that lets you upload a PDF and ask questions about it in plain English — answers are generated by an LLM but grounded strictly in the document's actual content.

🔗 **Live API:** https://docuchat-ai-1-1cnd.onrender.com/docs

> Note: This is deployed on a free-tier server, so the first request may take 30–50 seconds while it wakes up.

## Overview

DocuChat implements a full RAG pipeline: a PDF is split into chunks, each chunk is converted into a vector embedding, and those vectors are stored in a local vector database. When a question is asked, the most relevant chunks are retrieved and passed to an LLM as context — so the model answers using only what's actually in the document, rather than relying on general knowledge or hallucinating.

## Tech Stack

- **LLM:** Google Gemini (`gemini-3.6-flash`)
- **Embeddings:** Google Gemini Embeddings (`gemini-embedding-001`)
- **Orchestration:** LangChain
- **Vector Store:** ChromaDB
- **API:** FastAPI, Uvicorn
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Deployment:** Render

## How It Works

1. A PDF is uploaded through the `/upload` endpoint
2. The document is split into overlapping text chunks
3. Each chunk is converted into a vector embedding via the Gemini Embeddings API
4. Embeddings are stored in a ChromaDB vector store
5. A question sent to `/ask` is embedded the same way, and the most similar chunks are retrieved
6. Those chunks are passed to Gemini as context, and the model answers strictly from that context

## API Usage

**Upload a document:**

curl -X POST "https://docuchat-ai-1-1cnd.onrender.com/upload" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@document.pdf"

**Ask a question about it:**

curl -X POST "https://docuchat-ai-1-1cnd.onrender.com/ask" \
  -H "accept: application/json" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "question=What is this document about?"

**Example response:**

{
  "question": "What is this person's educational background?",
  "answer": "Based on the document, the person's educational background is: Bachelor of Computer Applications (BCA), Yenepoya Deemed to be University (2024 – Present), specializing in AI, Machine Learning, and Cloud Computing."
}

## Running Locally

git clone https://github.com/jidil-safa/docuchat-ai.git
cd docuchat-ai

pip install -r requirements.txt

Create a `.env` file in the project root:

GEMINI_API_KEY=your_gemini_api_key_here

Run the API:

python -m uvicorn main:app --reload

Visit `http://127.0.0.1:8000/docs` to test it interactively.

### Running with Docker

docker build -t docuchat-api .
docker run -p 8000:8000 --env-file .env docuchat-api

## CI/CD

Every push to `main` triggers a GitHub Actions workflow that builds the Docker image, validating the app still builds correctly before deployment.

## Security Notes

- The Gemini API key is never committed to the repository — it's loaded from a local `.env` file (excluded via `.gitignore`) during development, and injected as a secure environment variable on Render in production.
